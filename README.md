# 拷贝台

安卓端拓印辅助工具。载入线稿 → 调整大小和位置 → 锁定屏幕 → 隔着纸描摹。

## 功能

- 从相册载入线稿图片
- 双指缩放、单指拖动、滑块精确缩放（0.5x ~ 3x，刻度吸附）
- 背景色白 / 黑切换
- 屏幕常亮
- 锁定模式：除锁定按钮外，屏幕其他区域全部不响应触摸，进入沉浸式全屏
- 1 秒内双击锁定按钮解锁

## 如何构建 APK（不需要装 Android Studio）

### 第一步：注册 GitHub 账号
如果你还没有，去 https://github.com 注册一个。

### 第二步：新建仓库
1. 登录 GitHub，点右上角 `+` → `New repository`
2. Repository name 填 `copyta`
3. 选 `Public` 或 `Private` 都可以
4. 勾选 `Add a README file`
5. 点 `Create repository`

### 第三步：逐个创建文件
按本项目文件清单，在仓库里逐个新建文件：

- 点 `Add file` → `Create new file`
- 文件名要包含完整路径，例如 `app/src/main/java/com/copyta/app/MainActivity.kt`
- 把内容粘贴进去
- 点 `Commit changes`

把清单里所有文件都建好。

### 第四步：触发构建
- 文件全部提交后，GitHub Actions 会自动开始构建
- 或者点仓库上方 `Actions` 标签 → 左侧 `Build APK` → 右侧 `Run workflow`

### 第五步：下载 APK
- 进 `Actions` 标签
- 点最新一次运行
- 页面底部 `Artifacts` 里有 `copyta-debug-apk`
- 点它下载，解压得到一个 `app-debug.apk`

### 第六步：安装到手机
- 把 APK 传到手机（微信、数据线、网盘都行）
- 在手机上点开 APK 安装
- 首次安装可能需要允许「安装未知来源应用」

## 使用方法

1. 打开「拷贝台」
2. 点「载入图片」，从相册选一张线稿
3. 用双指缩放、单指拖动调整图片，或拖滑块精确调整
4. 需要换背景色就点白/黑圆点
5. 调好后，点工具栏右侧的圆形按钮 → 锁定
6. 锁定后工具栏消失，只留一个圆形按钮，屏幕其他区域全部不响应
7. 开始隔着纸拓印
8. 结束时，1 秒内双击那个圆形按钮 → 解锁

## 已知限制

- Home 键、电源键无法屏蔽，这是安卓系统限制
- 部分手机厂商的系统底部手势可能有差异
